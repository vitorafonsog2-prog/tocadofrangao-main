# Toca do Frangão Landing Page

Crie uma landing page (página única, sem rotas internas) para a marca "Toca do Frangão", 

uma loja de frangos. O site deve ser 100% responsivo (mobile-first, já que a maioria 

dos clientes vai acessar pelo celular).

ESTRUTURA DA PÁGINA (nessa ordem):

1. HEADER/HERO

- Logo da marca no topo (vou enviar a imagem)

- Nome "Toca do Frangão" em destaque

- Frase de impacto/slogan sobre frango fresco e saboroso

- Fundo com imagem de um dos frangos ou cor sólida em tons quentes 

  (vermelho, laranja, amarelo — remetendo a churrasco/comida)

- Botão de destaque "Peça agora" que rola a página até a seção de pedidos

2. SEÇÃO "NOSSA HISTÓRIA"

- Texto contando a história da Toca do Frangão (vou fornecer o texto, 

  por enquanto use um texto placeholder editável)

- Layout com imagem ao lado ou atrás do texto

3. SEÇÃO "NOSSOS FRANGOS" 

- Grid/carrossel de cards apresentando os produtos

- Cada card com: foto do frango, nome do produto, breve descrição

- Vou enviar as fotos dos frangos para usar aqui

4. SEÇÃO "PEÇA AGORA" (parte mais importante)

- Três botões grandes e chamativos, um para cada canal:

  • Botão "Peça pelo iFood" (cor vermelha do iFood) → link: [SEU LINK DO IFOOD]

  • Botão "Peça pelo 99Food" (cor do 99) → link: [SEU LINK DO 99]

  • Botão "Peça pelo WhatsApp" (verde do WhatsApp, ícone de WhatsApp) 

    → link: https://wa.me/55SEUNUMEROAQUI

- Botões devem abrir em nova aba (target="_blank")

- Ícones das respectivas marcas em cada botão

5. FOOTER

- Logo pequeno

- Redes sociais (se tiver)

- Endereço/horário de funcionamento (se quiser)

- Direitos autorais

ESTILO VISUAL:

- Paleta de cores quentes (vermelho, laranja, marrom, amarelo) remetendo 

  a churrasco e comida

- Tipografia forte e amigável (fonte robusta para títulos, legível pro corpo)

- Botões grandes e com boa área de toque (importante pro mobile)

- Espaçamento generoso entre seções

- Animações suaves de entrada ao rolar a página (scroll reveal)
